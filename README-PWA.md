# PWAアイコンの作成方法

PWAを完全に機能させるには、以下のアイコン画像が必要です：
- icon-192.png (192x192ピクセル)
- icon-512.png (512x512ピクセル)

## アイコン作成方法

1. **オンラインツールを使用**（推奨）
   - https://realfavicongenerator.net/
   - https://www.pwabuilder.com/imageGenerator
   - アプリのロゴや画像をアップロードして、必要なサイズのアイコンを生成

2. **手動で作成**
   - 192x192と512x512のPNG画像を作成
   - 赤色（#dc2626）の背景に白いマイクアイコンなど、アプリのテーマに合わせたデザイン

3. **一時的なプレースホルダー**
   - 現在はmanifest.jsonでアイコンパスを指定していますが、実際のファイルがない場合は警告が表示されます
   - アイコンファイルを追加すると、PWAとして完全に機能します

## PWA機能

- ✅ Manifest.json（アプリのメタデータ）
- ✅ Service Worker（オフライン対応、キャッシュ）
- ✅ インストールプロンプト対応
- ⏳ アイコン画像（要追加）
